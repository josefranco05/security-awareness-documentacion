# Sentinel

Documentación de una plataforma de simulación y detección de phishing para pymes colombianas.

Este repositorio está organizado como un libro de [mdBook](https://rust-lang.github.io/mdBook/). La documentación técnica existente se incluye directamente, sin duplicar su contenido.

Para compilar localmente los diagramas Mermaid, instala el preprocesador con `cargo install mdbook-mermaid --locked --version 0.17.1`.
