# Sentinel

Documentación de una plataforma de simulación y detección de phishing para pymes colombianas.

Este repositorio está organizado como un libro de [mdBook](https://rust-lang.github.io/mdBook/). La documentación técnica existente se incluye directamente, sin duplicar su contenido.

## Desarrollo local

Instala [mdBook](https://rust-lang.github.io/mdBook/guide/installation.html) y ejecuta desde la raíz del repositorio:

```powershell
mdbook serve
```

Abre la dirección que indique el comando para consultar el libro con recarga automática. Para generar el sitio estático, ejecuta:

```powershell
mdbook build
```
